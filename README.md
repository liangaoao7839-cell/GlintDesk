# GlintDesk

Windows 桌面美化工具。

## 下载

在 [Releases](https://github.com/liangaoao7839-cell/GlintDesk/releases) 下载 Windows 10 / Windows 11 x64 安装包。

## 功能

- 居中悬浮栏、应用固定及运行中应用显示。
- 应用窗口恢复和最小化切换。
- 液态玻璃、磨砂玻璃、鱼眼放大和自动隐藏。
- 托盘应用面板，音量和网络工具。
- 设备电量、音乐控制和动态天气；兼容情况因设备和应用而异。
